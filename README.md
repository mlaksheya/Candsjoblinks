# CandS Job Links — GitHub Pages

Static website ready for GitHub Pages.

## Publish from mobile
1. Create a new **public** GitHub repository, for example `cands-job-links`.
2. Upload all files in this folder to the repository **root** (make sure `index.html` is at the root, not inside another folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then tap **Save**.
6. Wait a few minutes, then open the URL shown in **Settings → Pages**.

The site is a static HTML/CSS/JavaScript website and includes `.nojekyll` for direct static publishing.
